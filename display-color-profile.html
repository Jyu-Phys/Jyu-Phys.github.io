下次直接恢复

  1. 优先使用本机备份目录中现存的 display-color-approved.json 与 display-color-runtime.json。
  2. 需要立即恢复时运行 Restore-DisplayColor.cmd；正常恢复沿用已保存的基线。
  3. 查看 display-color-status.json 的操作结果；更改配色前先运行暂停命令。
  4. 若本机快照丢失，从下方公开 JSON 读取参数及基础曲线，再核实本机硬件身份并重建绑定。
