物理论文写作 writepra

核读原始研究、比较证据，组织文献综述与物理论文，检查物理问题、模型、观测量和结论是否一致。

登录 GitHub 查看技能文件 →

使用

使用有访问权限的 GitHub 账号登录后，可查看技能主文件。将文件放入 Codex 技能目录的 writepra 文件夹，在对话中使用 $writepra。

这里提供主文件，其中引用的配套指南和脚本未包含在内，相关功能需要对应文件才能完整使用。

适用范围

  • 独立文献综述、开题报告和学位论文综述部分。
  • 物理研究论文的摘要、引言、理论模型与计算方法、结果与讨论、结论和参考文献。
  • 比较文献中的研究条件和证据，梳理共识、分歧与仍待回答的问题。

写作与核查

  • 围绕明确的物理问题组织论证，区分直接结果、作者解释和推论。
  • 按章节核对模型、计算方法、图表、参考文献，以及结论的适用条件。
  • 研究论文默认参考 PRA 体例；用户或目标期刊有其他要求时，按指定格式执行。

生成与验收

按当前任务适用的执行位置和权限规则处理文件。交付前检查正文与图表、公式、引文和排版；未完成的检查应明确说明。
